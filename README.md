# Simgci Poultry Farm Management System

A simple PHP farm management system for broilers and egg orders.

## Setup
1. Place the `Simgci` folder in your WAMP `www` directory.
2. Open the project in your browser: `http://localhost/Simgci/`
3. Login with the default credentials:
   - Username: `admin`
   - Password: `farm1234`

## Features
- Customer management with contact details
- Broiler batch tracking and start/sell date updates
- Egg collection records every 2 hours
- Order management for broilers and eggs (30s, 60s, singles)
- Daily analytics, financial summary, and progress updates
- Notification log for customer updates

## Notes
- The database uses SQLite at `data/farm.db`
- Update customers and orders from the dashboard after login
